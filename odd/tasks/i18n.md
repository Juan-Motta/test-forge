# Feature: i18n

Branch: `feat/i18n` (on `feat/eval-cost`). Delivery: fast-forward into `main` with the stacked
branches and push (user keeps everything on `main`).

## Objective
English and Spanish UI, and judge results available in both languages so the report matches the
page language.

## Decisions (user, 2026-10-15)
- UI: one dictionary per language (en, es), EN/ES switch next to the theme switch; choice kept in
  a cookie so the server renders the right language (no flash); default from the browser's
  Accept-Language; `<html lang>` follows; URLs unchanged (no /es prefix). The public guide is
  translated too.
- Judge: keeps reasoning and scoring in English (judge v2 stability). After each judgement a
  translation pass with the chat model (gpt-6-luna) produces Spanish versions of the free-text
  fields (summary, per-criterion reasoning, suggestions, strengths, brief); both versions are
  stored; the report shows the page language. Evidence quotes and transcripts are never
  translated. The translation's token usage is added to the judge cost. Old judgements get a
  "Translate" action on demand.
